# Zhuo Zhang Personal Website

Static bilingual personal website for GitHub Pages.

## Files To Upload

- `index.html` - language landing page
- `en.html` - English profile page
- `zh.html` - Chinese profile page
- `styles.css` - site styling
- `assets/` - resume PDF, resume preview image, favicon
- `.nojekyll` - tells GitHub Pages to serve the files exactly as-is

## Publish With GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save. GitHub will show the public website URL after deployment.

## Updating Content

Edit `index.html`, `en.html`, or `zh.html` directly, then upload the updated files to GitHub.
